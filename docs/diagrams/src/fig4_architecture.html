Figure 4. KilosUnlad System Architecture (6-layer decoupled engine)

Docker Compose stack on the kilosunlad-network bridge; versions and ports from docker-compose.yml and the service Dockerfiles
LAYER 1Presentation

Desktop Web Portal client :3000

  • React 18 + Vite 5, TypeScript
  • Director, Super Admin, COA screens: dashboard, triage queue + SHAP drawer, dispatch modal, due process docket, audit chain inspector

Mobile Tablet App (PWA)

  • Service worker offline shell; tasks and drafts in IndexedDB (Dexie)
  • Web Crypto SHA-256 photo hashing, Geolocation API
  • Auto-sync of queued reports on reconnect

Session handling

  • HS256 JWT in sessionStorage, 900 s lifetime
  • 401 / expiry clears the session and returns to login
↕HTTP (JSON, multipart evidence uploads)
LAYER 2Edge Gateway

Nginx reverse proxy :80

  • /api/v1/ → server:5000, / → client:3000 (single origin, no CORS round trips)
  • client_max_body_size 30M for photo evidence, forwards X-Real-IP / X-Forwarded-For for audit actor IPs
  • TLS termination is not configured in the repository (port 80 only)
↕proxy_pass /api/v1/
LAYER 3Application Server

Node.js 20 + Express 4 :5000

  • authenticate (JWT) → allowRoles (RBAC) → scopeJurisdiction → validateBody (Joi, convert:false)
  • Status state machine, transactional dispatch / submit / notice / retention / appeal and hearing outcome / calamity toggle
  • Composite risk score, RA 11310 age-out, geofence (Haversine, 250 m)
  • Hash-chain sealing and GET /audit/verify-chain
LAYER 4AI Microservice

Python 3.10 + FastAPI :8000

  • POST /api/v1/predict-swdi: LightGBM v1 multi-class SWDI (6 proxy-means features)
  • SHAP TreeExplainer: top-3 signed attributions
  • POST /api/v1/score-atm-stream: Sangla-ATM velocity heuristic
  • Server falls back to a deterministic rule score if the service is down
↕Mongoose 8 (replica-set URI, sessions + transactions)   |   server → ML over HTTP on the bridge network
LAYER 5Database

MongoDB 6.0 replica set rs0 :27017

  • 6 collections: users, beneficiaries, external_records, verification_tasks, audit_logs, system_configs
  • app_user with kilosUnladAppRole: audit_logs is find / insert / createIndex / listIndexes only (append-only)
  • Indexes: 2dsphere on address.coordinates, compound (risk_assessment.is_flagged, address.municipality), unique sequence_index and entry_hash
  • Host port ${MONGO_EXTERNAL_PORT:-27017}, keyfile auth
LAYER 6Storage

Persistent evidence volume upload-data

  • Mounted at /app/uploads (UPLOAD_DIR) in the server container
  • Content-addressed: evidence/<sha256>, bytes re-hashed before storage; mismatch → 422 EVIDENCE_HASH_MISMATCH
  • Named volumes also persist mongo-data and the replica-set keyfile
Batch jobs (not request path): seed-ingest, seed-verify, seed-audit, audit-integrity (python:3.10-slim) and reset-demo run on demand via docker-compose run against the same database. replset-init runs rs.initiate() on first boot.
